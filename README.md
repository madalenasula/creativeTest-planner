# Creative Test Planner

Make the hunch testable. HTML/CSS/JavaScript app which turns marketing observations into falsifiable A/B experiments.

## First step: experiment builder

- Capture an observation, audience and channel.
- Define one variable, a control and a variant.
- Set a primary KPI and a minimum meaningful relative lift.
- Generate a hypothesis and execution protocol.
- Try the skincare example.

## Run locally

1. Open `index.html` in a browser. No dependencies, login or external API.

2. Save experiments locally, copy/export briefs, improve mobile layout

**Limitations:** The lift target is a practical threshold, not a statistical significance calculation.
Experiment: Every creative test should start with a clear observation, isolate one meaningful variable, define a measurable hypothesis, and specify how results will inform the next decision.
