How to run it
  1. Randomly split eligible users between A and B, where the platform supports a proper experiment.
  2. Hold audience, placement, timing, spend, copy and other creative elements constant. Change only.
  3. Before launch, define a realistic duration and required sample size. Judge the result against the primary metric and guardrail.

Decision rule: Adopt B only if it exceeds the predefined lift threshold, the guardrail is acceptable, and evidence is sufficient. Otherwise record the result as inconclusive or unsuccessful. This planner does not calculate statistical significance.
